# Changelog

All notable changes to Desktop Sticky Notes will be documented in this file.

## 0.1.4 - 2026-05-21

### Changed

- Changed the sticky note title strip to left-aligned layout.
- Hide the right-side scrollbar when the top title/action strip auto-hides.
- Force top-right action icons to use the current sticky note theme accent color instead of muted gray.

## 0.1.3 - 2026-05-21

### Changed

- Removed the secondary Obsidian/folder label from sticky windows.
- Removed the bottom status strip.
- Made title-bar action icons solid instead of semi-transparent.
- Auto-hide the title/action strip 3 seconds after the pointer leaves the sticky note.

## 0.1.2 - 2026-05-21

### Changed

- Removed the top-left new-note button from sticky windows.
- Removed the more-actions button and exposed all actions in the top-right title strip.
- Improved default width/height application for new sticky windows.
- Strengthened titlebar/chrome hiding behavior.

## 0.1.1 - 2026-05-21

### Changed

- Added a Windows Sticky Notes inspired surface.
- Added default hidden-titlebar mode and simplified top action strip.

## 0.1.0 - 2026-05-21

### Added

- Pin current or selected Markdown note as a desktop sticky note.
- Create new sticky note from the command palette.
- Always-on-top support, opacity setting, taskbar hiding, and position/size persistence.
- Preview/edit toggle with debounced auto-save back to the Markdown source file.
- Restore pinned sticky notes on Obsidian startup.
