# Desktop Sticky Notes 0.1.4

## Highlights

- Pin Obsidian Markdown notes as Windows-style desktop sticky notes.
- Left-aligned sticky title strip with theme-colored action icons.
- Auto-hide title/action strip after the pointer leaves the sticky note for 3 seconds.
- Hide the scrollbar when the title/action strip is hidden while keeping wheel scrolling available.
- Always-on-top, opacity, remembered position, remembered size, and startup restore.
- Preview/edit toggle with debounced auto-save back to the source Markdown file.

## Release assets required by Obsidian

Attach these files to the GitHub Release:

- `main.js`
- `manifest.json`
- `styles.css`

The release tag must be exactly `0.1.4` to match `manifest.json`.
